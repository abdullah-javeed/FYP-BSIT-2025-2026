# CultiKure: AI-Powered Plant Disease Detection 🌱

**CultiKure** is a web-based application designed to empower farmers and gardeners by using Artificial Intelligence to detect plant diseases and recommend cures instantly.

## 🚀 Project Overview
This project is developed as a **Final Year Project (FYP)** for BSIT (2025-2026). It aims to solve the problem of delayed disease diagnosis in agriculture by providing a simple, "Farmer-First" interface.

### ✨ Key Features
- **AI-Based Detection:** Uses **Plant.id API** to identify diseases from leaf images.
- **Smart Prescriptions:** Integrates **Google Gemini API** to generate detailed symptoms, causes, and cure plans (Organic & Chemical).
- **Scan History:** Saves previous diagnoses for future reference.
- **No Training Required:** Built on an API-First architecture, eliminating the need for complex model training.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (Responsive Design)
- **Backend:** Python (Flask Framework)
- **Database:** SQLite (Development) / Firebase (Future Scope)
- **External APIs:** Plant.id, Google Gemini
